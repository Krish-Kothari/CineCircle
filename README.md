# CineCircle Social Engine

A full-stack Movie & Show Recommendation, Personal Tracking, and Social Blend Platform.

## Architecture & Subject Mapping
- **ASD (Backend & Web):** Node.js, Express.js, Prisma ORM, React.js
- **DE (Database Engineering):** PostgreSQL (12 Normalized Tables, ACID Transactions, Native Array & CTE Analytics)
- **AD (Mobile Development):** React Native (Expo) Mobile Client

## Team Module Ownership
1. **Krish:** Auth, Taste Preferences, Watchlist & Episode Tracker (`tracker-auth` + `ad-mobile-app`)
2. **Harsh:** Multi-Platform Catalog, Community Reviews & Hybrid Recommendation Engine (`catalog-recs`)
3. **Aryan:** Friend Groups, Group Blend Matchmaker & Live Watch Polls (`social-groups`)
